# Browser runtime (UAT stand-in)

This folder stands in for a vendored copy of the agentic-web `agentify-website` skill's browser runtime, which is
nsdeploy's runtime at nsdeploy commit `53a787c` with the skill's edits. It is a stand-in for the Plumbline UAT worlds:
a few small files with the provenance lines a real copy carries, not the runtime itself. Do not change it here.
